# 用語集

## OID4VCI関連

| 用語 | 説明 |
|------|------|
| OID4VCI | OpenID for Verifiable Credential Issuance |
| HAIP | High Assurance Interoperability Profile |
| Credential Offer | WalletにCredential取得を促すURL |
| Pre-authorized Code | 事前認可コード（認可コードフローの簡略版） |
| tx_code | Transaction Code（追加認証用PIN等） |
| c_nonce | Client Nonce（Proof生成用、Nonce Endpointから取得） |
| Access Token | Credential取得用のトークン |

## クレデンシャル形式

| 用語 | 説明 |
|------|------|
| SD-JWT | Selective Disclosure JWT |
| VC | Verifiable Credential |

## 役割

| 用語 | 説明 |
|------|------|
| Issuer | Credential発行者 |
| Holder | Credential保持者（Wallet） |
| Verifier | Credential検証者 |
