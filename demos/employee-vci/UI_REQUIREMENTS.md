# Employee VCI UI 要件定義

## 概要
employee-vci（社員証クレデンシャル発行サーバー）のUI機能について整理するドキュメント

---

## 1. 対象ユーザー

### 1-1. 管理者（Issuer側）
- [ ] 社員情報の管理を行う担当者
- [ ] クレデンシャル発行の管理・監視を行う担当者

### 1-2. エンドユーザー（Holder側）
- [ ] 社員証クレデンシャルを取得する社員
- [ ] Pre-Authorized Code を受け取ってクレデンシャルを取得

---

## 2. 必要な画面・機能

### 2-1. 管理者向け機能

#### 社員管理
- [ ] 社員一覧表示
  - [ ] 検索・フィルタリング機能
  - [ ] ソート機能
- [ ] 社員登録
  - [ ] 社員番号、氏名、部署、性別などの入力
  - [ ] バリデーション
- [ ] 社員情報編集
- [ ] 社員情報削除

#### クレデンシャル発行管理
- [ ] Pre-Authorized Code 発行
  - [ ] 対象社員の選択
  - [ ] TX Code（PIN）の生成・設定
  - [ ] 有効期限の設定
  - [ ] 発行されたCodeの表示（QRコード含む）
- [ ] 発行履歴の表示
  - [ ] 発行日時、対象社員、使用状態などの確認
- [ ] 発行済みCodeの管理
  - [ ] 未使用/使用済みの状態確認
  - [ ] 有効期限の確認

#### ダッシュボード
- [ ] 発行統計
  - [ ] 総社員数
  - [ ] 発行済みクレデンシャル数
  - [ ] 未使用Code数
- [ ] 最近のアクティビティ

### 2-2. エンドユーザー向け機能

#### クレデンシャル取得フロー
- [ ] Credential Offer の表示
  - [ ] 受け取るクレデンシャルの情報表示
  - [ ] OpenID4VCI URL / QRコードの表示
- [ ] TX Code（PIN）入力画面（必要な場合）
- [ ] 取得完了画面
  - [ ] 次のステップの案内（ウォレットアプリでの受け取り方法など）

## 8. 参考資料・既存実装

### 8-1. 既存のエンドポイント
- `GET /.well-known/openid-credential-issuer` - Issuer Metadata
- `GET /.well-known/oauth-authorization-server` - Authorization Server Metadata
- `POST /token` - Token Endpoint
- `POST /credentials` - Credential Endpoint
- `POST /admin/register-employee` - 社員登録（既存）
- その他管理者向けエンドポイント

### 8-2. 現在の実装
- demos/employee-vci/src/routes/
- demos/employee-vci/views/（EJSテンプレート）
